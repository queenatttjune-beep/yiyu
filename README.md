# 一隅

常驻在 Mac 屏幕角落的小本子（默认右上角，可以拖到任何地方）：今天的待办、所有待办、提醒、备忘和日记放在一个浮动面板里。它浮在所有窗口上面，跟着你切换桌面和全屏应用；点它不会把你正在用的应用切走。

默认的皮肤叫「磁青泥金」：磁青纸的深蓝做底，泥金色只用在日期、勾选和当前页上，逾期和到点的东西用朱砂红。也可以换成别的皮肤，或者自己调配色和字体。

## 安装

需要 macOS 14 或更新版本，以及 Apple 的命令行工具（没有的话在终端运行 `xcode-select --install`，不需要装 Xcode）。

```bash
git clone https://github.com/queenatttjune-beep/yiyu.git
cd yiyu
./scripts/build-app.sh --install
```

脚本会编译、打包成 `/Applications/一隅.app` 并打开它。第一次打开时，macOS 会询问是否允许通知，选「允许」提醒才会弹出来；应用也会把自己加入登录项，开机自动出现。

## 用法

打开时是收起的：屏幕角落一个小圆标，画的是园林里的一扇月洞门，门里斜进来一枝梅。平时半透明，不抢眼；有提醒到时间时右上角会出现红点，小圆标会轻轻跳一下。

| 操作 | 方式 |
|---|---|
| 呼出并直接输入 | `⌃⌥T`（再按一次收起） |
| 收起 / 展开 | 点一下顶部日期那一块就收起成一个小圆标，再点小圆标就展开；也可以按 `Esc` 收起 |
| 移动面板 | 按住顶部日期那一块拖动（收起时拖小圆标）；位置会记住，「⋯ › 放回右上角」可复位 |
| 切换页面 | 点页签，或 `⌘1`–`⌘5` |
| 隐藏 / 显示、登录时打开、退出 | 菜单栏右侧的月门图标 |
| 换皮肤、改配色和字体 | 面板右上角的 `⋯` › 外观与皮肤，或菜单栏图标 › 外观与皮肤… |

- **今天**：只放今天要做的事。没做完的会留到第二天，标上「昨天」「3天前」。
- **待办**：所有想到要做的事。点右边的太阳就排进今天；右键可以「明天做」或改名，双击标题也能改。
- **提醒**：一句话写时间和事情，下面会先显示它理解成什么时间，回车添加。
  例子：`明天下午3点 交作业`、`30分钟后 关火`、`下周五 交报告`、`每天早上8点 吃药`、`工作日 9:30 站会`、`11月3号 体检`。
  不带上午/下午的「3点」按下午算；认不出时间时，会让你手动选。到点会弹系统通知，面板顶上也会出现红色横条，右键可以推迟 10 分钟或 1 小时。
- **备忘**：第一行当标题，可以置顶和搜索。
- **日记**：每天一篇，默认用宋体书写，显示农历。底部 14 个点是最近两周，点缀色表示那天写过，点一下就跳过去。右上角的「润色」可以让 AI 帮你改写，见「AI 润色日记」。

## AI 润色日记

随手记下今天发生了什么，再点日记页右上角的「润色」，选一种风格：

- **白描**：朴素准确，少修饰，让细节自己说话。
- **诗意**：舒缓、有画面感，含蓄地带出心情。
- **华丽**：辞藻典雅，讲究句式，可以化用古典意象。
- **自定义**：点「＋ 自定义」，起个名字，写一句要求，比如「平淡有味，多写吃食和草木」或「改成第三人称」。右键可以删掉。

润色好的版本先单独显示，原文不动；满意就点「用这一版」，想换个说法就点「再写一版」。替换之后、再次修改之前，标题旁边会有「撤销润色」，可以换回原文。AI 被要求只依据你写下的内容改写，不编造没发生的事。

第一次使用要填 AI 设置（润色界面右上角的齿轮）。支持所有 OpenAI 兼容接口，可以直接选 DeepSeek、通义千问、Kimi、智谱 GLM、OpenAI 或本地 Ollama，再填上你在服务商那里申请的 API 密钥；模型名可以改成你想用的。

- 密钥只存在这台 Mac 的「钥匙串」里，不会写进日记数据或备份。应用更新后第一次润色时，macOS 可能会问是否允许一隅读取钥匙串，选「始终允许」即可。
- 润色时，当天的日记会发给你设置的服务，费用按服务商的价格计算。不想让日记离开电脑，可以用本地 Ollama（地址 `http://localhost:11434/v1`，不需要密钥）。

## 外观与皮肤

内置六款皮肤：深色的磁青泥金、竹青、黛紫，浅色的宣纸、月白、藕荷。在面板右上角的 `⋯` 或菜单栏图标里打开「外观与皮肤」，点一下就换，屏幕角落的面板马上跟着变。

每款皮肤包括六种颜色（底色、输入框、点缀色、文字、次要文字、提醒色）、三种字体（标题、正文、日记）和字号。内置皮肤不会被改动：调整其中任何一项，会自动另存为「我的…」，之后可以改名、复制或删除。颜色可以用取色器选，也可以直接输入 `#RRGGBB`；文字和底色太接近时，设置页会提醒。

## 数据

全部保存在 `~/Library/Application Support/Yiyu/data.json`（菜单栏图标 › 打开数据文件夹），皮肤设置单独存在同一文件夹的 `appearance.json`。每天第一次改动前会把前一版复制到 `backups/`，保留最近 14 天。数据文件读不出来时，应用会把它改名另存，不会覆盖。

## 开发

只需要 Command Line Tools（不需要 Xcode）。

```bash
./scripts/test.sh                 # 核心逻辑单元测试（Swift Testing）
./scripts/build-app.sh            # 打包到 build/一隅.app
./scripts/build-app.sh --install  # 打包、替换 /Applications/一隅.app 并启动
./scripts/ui-tour.sh              # 界面冒烟测试：示例数据跑一遍各页面并截图到 build/tour/（含用本地假 AI 服务测润色）
```

`ui-tour.sh --interactive` 还会模拟点击和打字，期间测试面板会占用键盘约 15 秒，运行时不要在别处打字。

代码结构：

- `Sources/YiyuCore/` 纯逻辑，不依赖界面：数据模型、待办/提醒/备忘/日记的增删改（都返回新数组）、中文时间解析 `QuickTimeParser`、润色的风格与请求 `WritingStyle` / `Polish`、皮肤 `Skin` / `SkinBook` 与它的存储 `AppearanceStore`、JSON 存储 `DataStore`、日期文案 `Labels`。
- `Sources/Yiyu/AI/` AI 润色：钥匙串里的密钥、AI 设置、一次只跑一个请求的 `DiaryPolisher`。
- `Sources/Yiyu/App/` 应用外壳：浮动面板、全局快捷键（Carbon，无需辅助功能权限）、菜单栏、系统通知、登录项、`AppModel`（唯一修改数据的地方，改动后 0.6 秒自动保存）、`AppearanceModel`（皮肤设置，同样自动保存）和外观设置窗口。
- `Sources/Yiyu/Views/` SwiftUI 页面；`Theme` 从当前皮肤取颜色和字体，`Views/Appearance/` 是外观设置页。
