# 一隅

常驻在 Mac 屏幕角落的小本子（默认右上角，可以拖到任何地方）：今天的待办、所有待办、提醒、备忘和日记放在一个浮动面板里。它浮在所有窗口上面，跟着你切换桌面和全屏应用；点它不会把你正在用的应用切走。

默认的皮肤叫「磁青泥金」：磁青纸的深蓝做底，泥金色只用在日期、勾选和当前页上，逾期和到点的东西用朱砂红。也可以换成别的皮肤，或者自己调配色和字体。

## 安装

需要 macOS 14 或更新版本，以及 Apple 的命令行工具（没有的话在终端运行 `xcode-select --install`，不需要装 Xcode）。

```bash
git clone https://github.com/queenatttjune-beep/yiyu.git
cd yiyu
./scripts/build-app.sh --install
```

脚本会编译、打包成 `/Applications/一隅.app` 并打开它。第一次打开时，macOS 会询问是否允许通知，选「允许」提醒才会弹出来；应用也会把自己加入登录项，开机自动出现。

## 用法

打开时是收起的：屏幕角落一个小圆标，画的是园林里的一扇圆窗，花枝从窗外斜入，穿过窗沿，花形随时节变化。平时半透明，不抢眼；有提醒到时间时右上角会出现红点，小圆标会轻轻跳一下。

小圆标有八种花景：一、二月梅花，三月玉兰，四月海棠，五、六月栀子，七、八月荷花，九月桂花，十、十一月菊花，十二月山茶。这是按月令选择的园林意象，不是当地实际花期预报。设置天气城市后，按该城市的时区换日、换月；南半球城市的花景顺移六个月，未设置城市时按本机日期选择北半球花景。菜单栏也跟着换成简化的当季花形。

设置好天气后，晴天添日光，晴夜有月光，雨雪和雾在花枝后面流动。四级及以上风力时枝叶稍微倾斜，鼠标经过会轻轻摇一次；系统开启「减少动态效果」时天气静止、枝叶不摇动。夜景优先按城市预报里的日出、日落判断，缺少数据时按当地时间 19:00 至次日 6:00 显示月色。天气直接复用现有缓存，不增加请求；实况超过一小时改看当前钟点的逐小时预报，没有对应预报、城市不匹配或缓存超过六小时，就只显示当季花景与昼夜变化。鼠标停在小圆标上能看到花名、当前状态和天气摘要。

| 操作 | 方式 |
|---|---|
| 呼出并直接输入 | `⌃⌥T`（再按一次收起） |
| 收起 / 展开 | 点一下顶部日期那一块就收起成一个小圆标，再点小圆标就展开；也可以按 `Esc` 收起 |
| 移动面板 | 按住顶部日期那一块拖动（收起时拖小圆标）；位置会记住，「⋯ › 放回右上角」可复位 |
| 切换页面 | 点页签，或 `⌘1`–`⌘5` |
| 隐藏 / 显示、登录时打开、退出 | 菜单栏右侧的月门图标 |
| 换皮肤、改配色和字体 | 面板右上角的 `⋯` › 外观与皮肤，或菜单栏图标 › 外观与皮肤… |
| 天气和穿衣建议 | 点顶部的天气，或 `⋯` › 天气设置…，见「天气与穿衣」「天气氛围」 |

- **今天**：只放今天要做的事。没做完的会留到第二天，标上「昨天」「3天前」。设置好天气后，最上面会有一张穿衣建议卡片。
- **待办**：所有想到要做的事。点右边的太阳就排进今天；右键可以「明天做」。鼠标移到条目上点铅笔、双击标题或右键选「编辑」，可以修改内容和计划日期；点「保存」或按回车保存，点「取消」或按 `Esc` 放弃修改。「今天」页也能编辑。
  「今天」和「待办」的输入框都能识别常见中文日期及口语任务，例如 `把明天的周报写了` → 明天的「写周报」、`后天买牛奶`、`下周五交报告`、`11月3号体检`。识别结果会在回车前显示；明确说出的日期优先于所在页面，未来的事情会留在「待办」并标上日期，到那天再进入「今天」。没说日期时，「今天」页默认今天，「待办」页默认不排期。识别在本机完成，不调用 AI 服务，也不创建系统提醒。
- **提醒**：一句话写时间和事情，下面会先显示它理解成什么时间，回车添加。
  例子：`明天下午3点 交作业`、`30分钟后 关火`、`下周五 交报告`、`每天早上8点 吃药`、`工作日 9:30 站会`、`11月3号 体检`。
  不带上午/下午的「3点」按下午算；认不出时间时，会让你手动选。到点会弹系统通知，面板顶上也会出现红色横条，右键可以推迟 10 分钟或 1 小时。
  点条目上的铅笔、双击内容或右键选「编辑」，可以修改内容、提醒时间和重复规则；保存后通知会按新设置更新。已完成的提醒只改内容仍保持完成，修改时间或重复规则会重新启用；重复提醒修改的是后续整个安排。
- **备忘**：第一行当标题，可以置顶和搜索。
- **日记**：每天一篇，默认用宋体书写，显示农历。底部 14 个点是最近两周，点缀色表示那天写过，点一下就跳过去。右上角的「润色」可以让 AI 帮你改写，见「AI 润色日记」。

## AI 润色日记

随手记下今天发生了什么，再点日记页右上角的「润色」，选一种风格：

- **白描**：朴素准确，少修饰，让细节自己说话。
- **诗意**：舒缓、有画面感，含蓄地带出心情。
- **华丽**：辞藻典雅，讲究句式，可以化用古典意象。
- **自定义**：点「＋ 自定义」，起个名字，写一句要求，比如「平淡有味，多写吃食和草木」或「改成第三人称」。右键可以删掉。

润色好的版本先单独显示，原文不动；满意就点「用这一版」，想换个说法就点「再写一版」。替换之后、再次修改之前，标题旁边会有「撤销润色」，可以换回原文。AI 被要求只依据你写下的内容改写，不编造没发生的事。

第一次使用要填 AI 设置（润色界面右上角的齿轮）。支持所有 OpenAI 兼容接口，可以直接选 DeepSeek、通义千问、Kimi、智谱 GLM、OpenAI 或本地 Ollama，再填上你在服务商那里申请的 API 密钥；模型名可以改成你想用的。

- 密钥只存在这台 Mac 的「钥匙串」里，不会写进日记数据或备份。应用更新后第一次润色时，macOS 可能会问是否允许一隅读取钥匙串，选「始终允许」即可。
- 润色时，当天的日记会发给你设置的服务，费用按服务商的价格计算。不想让日记离开电脑，可以用本地 Ollama（地址 `http://localhost:11434/v1`，不需要密钥）。

## 天气与穿衣

设置好以后，面板顶部日期右边显示现在的天气和温度，下面一行是今天的最低和最高温；鼠标停上去能看到体感温度、湿度和风力。今天页最上面有一张穿衣卡片，比如：

> **今日穿衣 · 舒适**　长袖衬衫或 T 恤；早晚只有 17°，带件薄外套；下午降水概率 55%，记得带伞。

穿衣建议按白天（8 点到 20 点）还没过去的那几个小时的**体感温度**分七档，从「寒冷」（羽绒服）到「炎热」（短袖短裤）。早晚温差大、可能下雨或下雪、风大、紫外线强时，会再补一句。18 点以后，卡片换成明天的建议。点卡片右上角的 × 当天就不再显示。

每天早上 7:30 还会发一条系统通知，写着今天的温度和穿衣建议，时间可以改，也可以关掉。到点时会现取预报再发；那时电脑在睡眠的话，会在中午前第一次唤醒时补发，过了中午就不补了。

天气数据来自[和风天气](https://www.qweather.com/)，需要你自己的免费账号：

1. 在[和风天气控制台](https://console.qweather.com/)注册，创建一个项目，给它添加「API KEY」凭据。
2. 在控制台的「设置」里找到你的 API Host（形如 `abcxyz.qweatherapi.com`）。
3. 点面板顶部的「设置天气」，填上 API Host 和 API KEY，搜索并选好城市，点「保存」。

- 每 30 分钟刷新一次，一次 3 个请求，一个月大约 4500 次，在和风天气每月 5 万次的免费额度之内。取不到时会显示上次的天气，超过 6 小时的会变淡。
- 密钥只存在这台 Mac 的钥匙串里；发给和风天气的只有城市的经纬度，待办、日记这些都不会发出去。

## 天气氛围

设置好天气以后，面板会跟着窗外的天气变：

| 窗外 | 面板 | 收起时的小圆标 | 菜单栏图标 |
|---|---|---|---|
| 小雨、毛毛雨 | 蒙蒙细雨斜斜地飘，带一层薄雾 | 花枝后的圆窗里飘着雨丝 | 当季花旁几道雨丝 |
| 中雨、大雨、雷阵雨 | 雨丝更密、更快，仍是细线 | 同上，更密 | 同上 |
| 晴天 | 右上角（温度那里）洒下暖光，几道光束慢慢摆动 | 花枝后有一轮太阳 | 当季花旁一个太阳 |
| 晴夜（日落到日出） | 右上角一点月光，深色皮肤上还有星星闪烁 | 花枝后有新月和星星 | 当季花旁一弯新月 |
| 雪 | 雪花慢慢落下 | 花枝后落雪 | 当季花旁几点雪 |
| 雾、霾、沙尘 | 几层薄雾左右飘移 | 花枝后飘雾 | 当季花旁几道横线 |
| 多云、阴 | 和平时一样 | 保留当季花景 | 保留当季花形 |

雨雪越往下越淡，不挡清单上的字；浅色皮肤上雨丝是铅灰色，雪是带灰边的白点。用的是最近一次的实况，超过一小时就改看这个钟点的逐小时预报；预报超过 6 小时没更新就不再画。白天黑夜按预报里当天的日出、日落时间分，顶部的天气图标也跟着换成月亮。

- 雨雪是预先画好的几层，交给系统的 Core Animation 慢慢往下滑，每秒最多 24 帧，光和雾每秒 20 帧左右。界面冒烟测试会检查应用进程在细雨时的 CPU 开销。
- 系统设置 › 辅助功能 › 显示 里打开「减弱动态效果」时，画面是静止的。
- 不想要的话，在天气设置里关掉「面板跟着天气变化」：面板停止天气氛围，小圆标保留当季花景和静态昼夜变化，菜单栏只保留当季花形。
- Finder 和启动台里的 App 图标是固定的，不跟天气变。

## 外观与皮肤

内置六款皮肤：深色的磁青泥金、竹青、黛紫，浅色的宣纸、月白、藕荷。在面板右上角的 `⋯` 或菜单栏图标里打开「外观与皮肤」，点一下就换，屏幕角落的面板马上跟着变。

每款皮肤包括六种颜色（底色、输入框、点缀色、文字、次要文字、提醒色）、三种字体（标题、正文、日记）和字号。内置皮肤不会被改动：调整其中任何一项，会自动另存为「我的…」，之后可以改名、复制或删除。颜色可以用取色器选，也可以直接输入 `#RRGGBB`；文字和底色太接近时，设置页会提醒。

## 数据

全部保存在 `~/Library/Application Support/Yiyu/data.json`（菜单栏图标 › 打开数据文件夹），皮肤设置单独存在同一文件夹的 `appearance.json`，天气设置和最近一次的预报存在 `weather.json`。每天第一次改动前会把前一版复制到 `backups/`，保留最近 14 天。数据文件读不出来时，应用会把它改名另存，不会覆盖。

## 开发

只需要 Command Line Tools（不需要 Xcode）。

```bash
./scripts/test.sh                 # 核心逻辑单元测试（Swift Testing）
./scripts/build-app.sh            # 打包到 build/一隅.app
./scripts/build-app.sh --install  # 打包、替换 /Applications/一隅.app 并启动
./scripts/ui-tour.sh              # 界面冒烟测试：示例数据跑一遍各页面并截图到 build/tour/（含用本地假 AI 服务测润色、假和风天气测天气和天气氛围）
./scripts/ui-tour.sh --editing    # 编辑回归测试：隔离数据，验证待办和提醒的编辑、保存、取消并截图
./scripts/ui-tour.sh --garden     # 花景验收：六款皮肤、八种花、天气模拟和菜单栏同步，截图到 build/garden-tour/
```

`ui-tour.sh --interactive` 还会模拟点击和打字，期间测试面板会占用键盘约 15 秒，运行时不要在别处打字。几种模式都在真实桌面上跑：运行时点到测试面板，它会收起或抢走键盘，后面的检查可能失败；默认模式下日志里会记一句「a click from outside the tour」。菜单栏图标的各种天气画在 `build/tour/icons/statusbar.png`。

代码结构：

- `Sources/YiyuCore/` 纯逻辑，不依赖界面：数据模型、待办/提醒/备忘/日记的增删改（都返回新数组）、中文时间解析 `QuickTimeParser`、润色的风格与请求 `WritingStyle` / `Polish`、皮肤 `Skin` / `SkinBook` 与它的存储 `AppearanceStore`、和风天气的请求和解析 `QWeatherAPI` / `QWeatherResponse`、穿衣规则 `OutfitAdvisor`、早晨提醒的时间 `MorningBriefing`、天气设置与缓存 `WeatherStore`、天气氛围 `WeatherScene` 和雨雪的落点 `PrecipitationField`、JSON 存储 `DataStore`、日期文案 `Labels`。
- `Sources/Yiyu/AI/` AI 润色：钥匙串里的密钥、AI 设置、一次只跑一个请求的 `DiaryPolisher`。
- `Sources/Yiyu/App/` 应用外壳：浮动面板、全局快捷键（Carbon，无需辅助功能权限）、菜单栏、系统通知、登录项、`AppModel`（唯一修改数据的地方，改动后 0.6 秒自动保存）、`AppearanceModel`（皮肤设置，同样自动保存）和外观设置窗口。
- `Sources/Yiyu/Weather/` 天气：联网取数的 `WeatherClient`，和负责定时刷新、失败退避、发早晨通知的 `WeatherModel`。
- `Sources/Yiyu/Views/` SwiftUI 页面；`Theme` 从当前皮肤取颜色和字体，`Views/Appearance/` 是外观设置页，`Views/Weather/` 是顶部天气、穿衣卡片和天气设置页，`Views/Sky/` 是天气氛围：面板背后和小圆标圆窗里的 Core Animation 图层（雨雪用预绘图层循环下滑，光和雾用图层动画）。菜单栏的天气与花形组合在 `App/StatusBarIcon.swift`，花形路径与小圆标共用。
