# 一隅图标 · 参考笔记

这次要做三样东西：收起时的小圆标（52pt，会跟着皮肤换色）、App 图标（Dock / Finder）、菜单栏模板图标（18pt）。下面是挑出来对照的参考，以及每个参考能借鉴的地方。

## 规范

**Apple《Human Interface Guidelines · App icons》（macOS 26）**
- 只讲一个概念、一个隐喻，一眼认得出。
- 图标要缩到 16×16（Finder 列表、菜单），细线和碎细节在小尺寸会糊掉，每个尺寸都要看。
- 尽量不放文字：小尺寸读不清，也不随语言变化；应用名本来就写在图标旁边。
- 前景边缘要清楚，背景要能衬托前景；系统还会做深色、着色、透明几种外观，图形单色化之后也要认得出。
- 圆角方块是统一的外形，形状不对的图标在 macOS 26 会被装进一个灰色底框里。

## Mac 上做得好的图标

**Things 3（Cultured Code）**：蓝底上一个白色勾选框。整个应用的意思就压在一个形状里，剪影干净，16px 也认得出。渐变和投影很克制，只用来托出那一个形状。
→ 借鉴：一个主形，其他都让位。

**Day One**：蓝底一条白色书签丝带。日记 = 书签，隐喻直接，几乎是一笔画完。
→ 借鉴：用"阅读/书写时留下的记号"讲日记，正是一隅的折角方向想走的路。

**Bear**：一个熊头剪影，轮廓本身就是名字。线条有粗细节奏，缩小后仍是一只熊。
→ 借鉴：名字能变成形状就别写字。

**Craft（2021 版，Gavin Nelson 设计）**：几层圆润的形状叠出纵深，材质和光影做得很细，但站远了仍是一个简单的块面。
→ 借鉴：大尺寸可以有质感，小尺寸要退回到干净的剪影。分开考虑 1024 和 16 两种尺寸。

**Apple 自家的「备忘录」「图书」**：一张纸的顶边、一本摊开的书，都是生活里的实物，配一种主色。
→ 借鉴：实物隐喻 + 单一主色，系统感强。

## 中式意象

**磁青纸泥金写经**：深蓝染纸、金粉写字，纸上有金色界栏。一隅的配色就是从这里来的。金只用在要紧处，大面积留给磁青。

**南宋马远「马一角」、夏圭「夏半边」**：山水只画在画面一角，其余大片留白，一角就是一方天地。这和"一隅"的字面意思几乎完全重合。

**园林月洞门**：墙上开一个圆，门里一枝梅、一角景。圆形本身就是小圆标的外形，"门里的小天地"正是这个应用想做的事。

**印章（闲章）**：文人在画角钤一方小印，朱文、白文、破边，都是在很小的方寸里做设计。印章天生适合小尺寸：一个实心方块，里面镂空。

**「照千一隅，此则国宝」**（最澄《山家学生式》）：守住、照亮自己的一个角落。一盏小灯的形象温暖、剪影清楚，也适合做"有提醒"时的状态。

## 小结：评判方案的几条尺子

1. 只有一个主形，16px 下剪影还在。
2. 隐喻扣住"一隅"：一个角落，一方小天地。
3. 金色是点睛，不铺满；朱砂红只留给逾期和到点提醒，图标本身不用红。
4. 小圆标只用皮肤的颜色角色（底色 paper、强调色 accent、字色 ink / inkMuted），在浅色皮肤上同样成立。
5. 三处图标（小圆标、App 图标、菜单栏）是同一个形状的三种尺寸，不是三张不同的画。
